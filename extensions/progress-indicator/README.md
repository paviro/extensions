# Progress Indicator

Shows a half-filled status circle for partially played podcasts and iTunes U items in Apple's item lists, including an unfinished replay. Unplayed and completed items, group rows and All rows keep the stock look. The circle follows the saved resume position, or the live one while the item plays, and keeps the stock outline and colours.

| | |
|---|---|
| Default | on |
| Memory | image, plus 16 bytes per list model it has drawn in, freed with the model or on disable |
| Settings | none |

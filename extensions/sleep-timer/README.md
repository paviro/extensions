# Sleep Timer

Based on [Sleep Timer shortcut](https://github.com/RepriseOS/repriseos/pull/75) by kayboll in RepriseOS.

Adds Sleep Timer to the Now Playing context menu (hold Select) of a song, podcast episode, iTunes U episode or audiobook. It opens a list of Apple's sleep timer choices, Off, 15, 30, 60, 90 and 120 Minutes, with the active one highlighted. Choosing one sets Apple's timer, the one Extras > Alarms > Sleep Timer sets, and returns to Now Playing.

While the timer runs, Now Playing shows the minutes left and a moon before the shuffle icon. From an hour the minutes read h:mm.

| | |
|---|---|
| Default | on |
| Memory | image only; about 1 KB for the Now Playing image from setting the timer until Now Playing shows it stopped, and a 4.6 KB scratch while its minutes are drawn |
| Settings | none |

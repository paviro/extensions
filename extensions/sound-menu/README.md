# Sound Menu

Adds Settings > Sound, a menu that gathers the sound settings. Apple's Volume Limit, EQ and Sound Check rows move into it from Settings, and the audio extensions' rows that sit after them in Settings sit after them in Sound too. The Sound row sits where Volume Limit was. With the extension off, every row is back in its place in Settings.

The moved rows stay Apple's: the same titles, values, screens and preview pane.

| | |
|---|---|
| Default | off |
| Memory | about 6 KB once opened: the list, its bindings and clones of the three rows' Settings layouts |
| Settings | none |

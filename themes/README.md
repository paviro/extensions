# themes

First-party themes for RepriseOS and the compiler that builds a theme folder into one `/Reprise/Themes/<id>.rvt` file for the Appearance extension. A theme sets colours, accents and rendering options, and replaces or derives Apple's bitmaps. Authoring needs only Python.

| Directory | Theme | What it looks like | Appearances |
|---|---|---|---|
| `themes/classic` | Classic | The stock art relit, recoloured and inverted on the iPod. Ships inside the Appearance extension | dark |

## Build

From the `themes/` directory:

```sh
python3 -m rvt compile themes/classic --allow-reserved   # into dist/classic/classic.rvt
python3 -m rvt inspect dist/classic/classic.rvt
```

Copy `<id>.rvt` to `/Reprise/Themes/`. Classic's recolour rule files are generated by `themes/classic/recolor.py --firmware osos.bin` from a decrypted 2.0.5 firmware. `--check` confirms the committed files match. The other commands, the tests and the package layout are in [The compiler](docs/toolchain.md).
